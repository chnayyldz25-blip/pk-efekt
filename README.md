# PK Efekt Sunucusu

Studio'ya eklenecek overlay ve telefondan tetikleyen kumanda.

- Overlay (Studio, Bağlantı kaynağı, 1080x1920):  /overlay?key=ANAHTAR
- Kumanda (telefon):                               /panel?key=ANAHTAR

ANAHTAR yerine istediğin kelimeyi yaz (örn. busra). İkisinde de aynı olmalı.
Test için overlay'e &test=1 ekle: sol altta "Efekti oynat" tuşu ve sağ altta bağlantı noktası çıkar.
